# Project Statement

## Campus Lost & Found Management System

The **Campus Lost & Found Management System** is a console-based Java application designed to help students manage and keep track of lost and found items within a college campus.

In a college environment, students often lose personal belongings such as ID cards, wallets, water bottles, books, earphones, and other items. Keeping records of these items manually can be difficult. This project provides a simple way to report, search, manage, and claim such items using a menu-driven application.

The system allows users to register themselves, report lost items, report found items, view all available records, search for items, claim found items, and remove records when they are no longer required.

The project is developed using basic Java programming concepts including **Classes and Objects, Constructors, Encapsulation, ArrayList, Methods, Loops, Conditional Statements, Exception Handling, and File Handling**.

The application stores user and item records in simple text files so that the data can be loaded again when the program is restarted.

## Main Functions

* Register a new user
* Report a lost item
* Report a found item
* View all lost and found items
* Search for an item
* Claim a found item
* Remove an item
* Save records to files
* Load previously saved records
* Handle invalid user input
